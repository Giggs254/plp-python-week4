# PLP Python Week 4

This repository contains my solutions for the PLP Python Week 4 functions assignment.

## Files

* `welcome.py` - Contains a `welcome()` function that returns a personalized PLP welcome message.
* `toolbox.py` - Contains the `double()`, `is_pass()`, and `greet()` functions for practicing Python functions, return values, and default parameters.
* `README.md` - Provides an overview and description of the files in this assignment.

## Hardest Function

The `greet()` function was the hardest to write because it uses an optional greeting with a default value. It required understanding how default parameters work when no greeting is provided.
